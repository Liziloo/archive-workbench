# Archive Workbench

Archive Workbench (AW) is a workbench for processing archival materials by one archivist in preparation for archival storage and publication through Omeka S.

AW is designed to reduce repetitive work while preserving human control over archival judgment. It coordinates digital assets, research, metadata, processing, and publication preparation without replacing the systems responsible for those functions.

## Guiding principle

> If a computer can do it reliably, with no danger to the archive or its publication, it should.

Routine and reversible work should be automated wherever practical. Historical interpretation and consequential archival actions remain under human supervision and approval.

## Development

AW is developed through thin, usable vertical slices of real archival work.

The development loop is:

> Define behavior → write the test → make it pass → refactor → repeat.

Tests define intended behavior before implementation. Each slice should be usable and tested against real archival material before the system is expanded.

## Scope

AW prepares and processes archival material for preservation and publication.

It does not replace:

- Omeka S
- Obsidian
- DigiKam
- transcription software
- image-editing software
- long-term digital preservation systems
